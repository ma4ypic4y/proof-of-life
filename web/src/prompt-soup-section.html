Act two · the chemistry is a language model

A primordial soup of prompts

BFF works because code and data share one tape. A language model gives you that for free: any text can be read as instructions or as input. So we kept the protocol and swapped the chemistry. The soup is 128 short texts that start as random dictionary words. Each epoch they are paired at random, and in each pair one text becomes the system prompt and the other the user message of a small open model (Qwen2.5-1.5B-Instruct, run locally). The reply, cut to 160 characters, overwrites the user message. No task, no goal, no selection.
